# Smasher The Battlebot by Hamish and Misha

A quest-by-quest guide two sixth graders are using to build a one-pound ramming battlebot
with a Raspberry Pi and a Freenove starter kit.

Live site: https://borzov.ca/smasher/

Plain static site: `index.html`, `css/`, `js/`, `img/`. No build step. Progress is stored in the
visitor's browser (localStorage) only.

To run locally: `python -m http.server --directory .` and open http://localhost:8000.

Wiring and pin choices follow the Freenove Ultimate Starter Kit tutorial (CC BY-NC-SA 3.0).
The catalogue photo `img/kit.jpg` is Freenove's.
